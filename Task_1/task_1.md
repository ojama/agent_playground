# Task 1: 搜索GitHub上热门的AI相关开源项目

## 任务目标
搜索并整理GitHub上最受欢迎的AI相关开源项目，为开发者提供一个全面的AI项目资源列表。

## 搜索范围
1. 人工智能 (Artificial Intelligence)
2. 机器学习 (Machine Learning)
3. 深度学习 (Deep Learning)
4. 自然语言处理 (NLP)
5. 计算机视觉 (Computer Vision)
6. 大语言模型 (LLM)
7. AI代理 (AI Agents)

## 筛选标准
- Star数量 > 10,000
- 活跃维护的项目
- 开源且有实际应用价值
- 涵盖不同的AI领域和应用场景

## 输出要求
将搜索结果整理成结构化文档，包括：
- 项目名称和链接
- 项目描述
- 主要技术栈
- Star数量
- 主要特性和应用场景
